# nova-club-site — Contexte

## IMPORTANT — À faire en premier à chaque session
Lire `SPRINT.md` (même dossier) avant toute chose.
Ce fichier contient l'état exact du projet, les tâches en cours et la prochaine action à exécuter.
Le mettre à jour à la fin de chaque session.

## Le site
Site vitrine B2B NovaRythm Clubs — 4 pages statiques (Accueil, Offre clubs, Catalogue B2B,
Contact), construites avec les composants `@novarythm/design-system` (vendored, voir README.md).
Hébergé sur GitHub Pages, domaine `novarythmclubs.com`. Déploiement auto sur push `main`
(`.github/workflows/deploy.yml`).

Cible : clubs de gymnastique rythmique (B2B), pas les gymnastes individuelles (ça, c'est le
site principal `novarythm.com` / repo `theme`, un projet à part).
